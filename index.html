Team Collaboration Project

Learning Git, GitHub and teamwork

About Our Project

This project demonstrates how software developers collaborate using GitHub. Team members work on separate branches and contribute improvements and proper working.

Project Objectives

  • Create and manage a GitHub repository.
  • Clone the project to a local computer.
  • Create branches for individual contributions.
  • Commit and push code changes.
  • Review and merge pull requests.

Team Contributions

  • Manager: Repository setup and collaboration.
  • Member 1: Improve the project introduction.
  • Member 2: Add a new project objective.
  • Member 3: Improve page styling.
