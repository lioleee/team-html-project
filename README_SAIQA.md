# StartUp — Business Landing Page

## Project Overview
StartUp is a simple and responsive business landing page designed to introduce digital services through a clean and user-friendly interface. The project demonstrates the use of HTML, CSS, and JavaScript to create a basic interactive website.

## Features
- **Business Introduction:** Presents the StartUp brand and its main message.
- **Get Started Interaction:** Displays a welcome message when the user clicks the Get Started button.
- **Theme Toggle:** Allows users to switch between light and dark themes.
- **Interactive Button Styling:** Adds hover effects to improve user interaction.
- **Dynamic Footer:** Automatically displays the current year.

## Improvements Made
The original landing page was enhanced with small but meaningful improvements while preserving its simple design.

- Added JavaScript functionality to the Get Started button.
- Implemented a light/dark theme switch.
- Added hover styling for buttons.
- Updated the footer to display the year automatically.
- Improved styling for a more consistent user experience.

## Technologies Used
- **HTML5:** Structures the webpage.
- **CSS3:** Handles layout, colors, themes, and hover effects.
- **JavaScript:** Implements interactive features and dynamic content.

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
